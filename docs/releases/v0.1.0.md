# ClassLens v0.1.0

ClassLens helps teachers inspect recurring patterns in free-text answers, trace
them to exact response evidence, and approve remediation grounded in their own
source material. This release shares the hackathon MVP under MIT, with preserved
third-party notices.

## Included

- CSV validation, pinned local embeddings, deterministic semantic grouping, and
  provisional Gemini labels with controlled fallback.
- Teacher group review, exact answer evidence, material ingestion and retrieval.
- Source-validated Gemini remediation with teacher editing and explicit approval.
- Follow-up comparison, PostgreSQL persistence, reload recovery, and printable
  approved evidence summaries.
- Versioned synthetic photosynthesis inputs, locked runtimes, local setup docs,
  and credential-free unit/fixture-browser CI plus disposable PostgreSQL checks.

## Requirements and limitations

Use Linux/WSL, the pinned Node 22 runtime, Python 3.11, PostgreSQL 17, and your own
Gemini key for the live local workflow. First startup downloads the embedding
model. The backend measured approximately 1.11 GB peak RSS; allow at least 2 GB
available backend memory. Provider usage may incur charges.

This is a synthetic-data demo. Authentication, API record ownership, institutional
privacy workflows, and spend controls are pending. Do not deploy an unrestricted
API or upload real student data. The hosted API is suspended.

Grouping is evidence for teacher review, not a diagnosis. Before/after changes
describe observation, not causal proof. Provider output remains provisional.
